# TinkerCraft icon

Matte toolbox artwork generated for this project at the user's request.
`tinkercraft.png` is the 1024px source; `tinkercraft-256.rgba` is unmultiplied
RGBA (256 × 256) embedded in the desktop executable. ICNS is used in the Mac
bundle; ICO is supplied for Windows shortcuts. Derivatives were generated with
Pillow using Lanczos resizing. No runtime image-decoding dependency is required.
