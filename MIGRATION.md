# Migration record and verification

## Authorization
User explicitly requested converting the entire project to native Rust in an
ArtCraft-like style, with cross-platform support from the start. User then removed
the previous 50% weekly-usage cap. Do not continue applying that cap or invent usage
readings. Existing TypeScript/Tauri checkpoint 6 is preserved separately.

## Ported from checkpoint 6

- Version 1–4 project migration; source-node model; validation and global IDs.
- Boxes, cylinders, spheres, cones; nested scoped solid/hole Boolean operations.
- Source/result preview and binary STL export in mm.
- Numeric edits, world-axis movement and rotation, gesture snapping/cancel/undo.
- Perspective/orthographic camera, standard views, orbit/pan/zoom and fit.
- Multiselection, group/ungroup, recursive duplicate/delete, primitive drop.
- Alignment and mirroring, including cone apex reversal and nested transforms.
- 100-step undo/redo, saved baselines, native open/save/save-as and close protection.
- Atomic writes, external-change detection, debounced recovery/restore.

UI behavior changes: native egui controls; rotate by dragging a colored axis
rather than a ring; holes use stippling; viewport capped at 900 pixels per dimension.
Native recovery is separate from old browser/Tauri recovery. Legacy project files remain readable; schema 6 saves require the new build. Camera, selection and undo history remain session-only.

## Verification performed in this environment

- Rust 1.99.1: full Linux desktop and CLI builds succeeded.
- `cargo check --workspace --target x86_64-pc-windows-gnu`: passed.
- `cargo check --workspace --target aarch64-apple-darwin`: passed.
- `cargo test --workspace --locked`: 15 engine test scenarios passed.
- One compatibility scenario compares 19 fixtures generated by the actual
  checkpoint-6 JavaScript/WASM engine against Rust volume and world bounds.
- Fixtures include the drilled plate, rotated/scaled group, each rotated primitive,
  three-axis mirroring and a horizontal hole.
- Additional tests compare reflected mesh vertex sets, group-hole scoping,
  transformed ungrouping, validation, recursive IDs, history/save baselines,
  external-file conflicts, projection and viewport picking.
- CLI validate/export/render exercised on the plate; exported STL has 788 triangles
  and expected volume 11803.790612309582 mm³. Render inspected internally.

Compile-time cross-target checks are not native Windows/macOS runtime tests. CI
workflow files are included but have not run on GitHub. Mac/Windows native dialogs,
OS shortcuts, graphics, install/uninstall, signing/notarization and packaged offline
runs remain target-machine checks. Bambu Studio import has not been verified.

## Known limits / unfinished MVP features

Further shapes; editing inside a group without ungrouping; nonuniform group scaling;
concurrent-instance recovery; GPU 3D renderer; native menus;
signed installers and automatic updates. These are not claimed complete.

Cross-platform portability is part of the native code and build matrix now; actual
release confidence still requires running the packages on all supported systems.

## Build notes

This container's compiler produced empty object files in some dependencies with
multiple codegen units. One codegen unit and disabled incremental/debug info fixed
its development build. Those conservative development settings are retained.
Release builds also use one codegen unit. Keep Cargo.lock and the
pinned toolchain; do not globally replace version strings inside dependency locks.

Binary/ASCII parsing, explicit units, bounded allocation, exact welding, topology
and self-intersection checks, review-before-add, embedded meshes, transforms,
Boolean cuts and one-step undo. Eight import regression scenarios passed alongside
the 15 migration scenarios. This checkpoint introduced schema 5 (checkpoint 9 advances it to schema 6).

Migration-stage Linux native window tests also verified numeric edit undo/redo,
move and rotate drag undo, grouping/ungrouping and recovery snapshot writing.

## Checkpoint 9 — resize handles and additional primitives

Wedge and roof shapes, per-local-axis center-anchored resizing, circular constraints,
uniform group resizing, snapping, live source preview, cancel and one-step undo.
Schema 6 reads legacy 1–5 and adds wedge/roof. Six new regression scenarios cover
volumes/bounds, STL round trips, three-axis asymmetric mirroring, preview/committed
geometry agreement, group scaling, resize rejection and scoped cuts/drop.

Modeling-only scope: a simple local tool for preparing objects for 3D printing.
No circuits, code blocks, cloud or classroom ecosystem are planned.

Final checkpoint-9 validation: all 29 engine tests, strict Clippy, rustfmt, Linux
release build, native-window regression script and Windows GNU/macOS ARM compile
checks passed. See CHECKPOINTS.md for precise limits and remaining platform tests.
